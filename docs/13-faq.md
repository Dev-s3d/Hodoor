# الأسئلة الشائعة (Frequently Asked Questions)

يحتوي هذا الملف على أكثر الأسئلة والاستفسارات والمشاكل شيوعًا المتعلقة بمشروع Hodoor وطريقة تشغيله وتطويره.

---

# مقدمة

تم إعداد هذا الملف لمساعدة:

* المطورين.
* مديري الأنظمة.
* المختبرين.
* المستخدمين الجدد.

على فهم المشروع وحل المشكلات الشائعة بسرعة.

---

# أسئلة التثبيت

## أين أضع ملفات المشروع؟

يعتمد ذلك على بيئة التشغيل المستخدمة.

### XAMPP

```text
C:\xampp\htdocs\Hodoor
```

### Laragon

```text
C:\laragon\www\Hodoor
```

### MAMP

```text
Applications/MAMP/htdocs/Hodoor
```

---

## كيف أقوم بإنشاء قاعدة البيانات؟

يمكن إنشاء قاعدة البيانات بالأمر التالي:

```sql
CREATE
DATABASE hodoor;
```

ثم استيراد ملف:

```text
database/hodoor.sql
```

---

## أين أعدل بيانات الاتصال بقاعدة البيانات؟

داخل ملف:

```text
config/database.php
```

أو داخل:

```text
classes/clsDatabase.php
```

حسب بنية المشروع.

---

## لا أستطيع الاتصال بقاعدة البيانات

تأكد من:

* اسم قاعدة البيانات.
* اسم المستخدم.
* كلمة المرور.
* تشغيل خدمة MySQL.

---

# أسئلة تسجيل الدخول

## نسيت كلمة مرور المدير

يمكنك تحديث كلمة المرور مباشرة من قاعدة البيانات.

مثال:

```sql
UPDATE users
SET password = 'new_password'
WHERE username = 'admin';
```

يفضل استخدام كلمة مرور مشفرة.

---

## تظهر رسالة "بيانات الدخول غير صحيحة"

تحقق من:

* اسم المستخدم.
* كلمة المرور.
* حالة الحساب.
* بيانات المستخدم داخل جدول users.

---

## لا أستطيع الدخول رغم صحة البيانات

تحقق من:

```text
status = 1
```

داخل جدول المستخدمين.

---

# أسئلة الصلاحيات

## لماذا لا تظهر بعض القوائم؟

لأن القوائم تعتمد على صلاحيات المستخدم الحالي.

مثال:

```text
Admin
Supervisor
Teacher
```

كل صلاحية ترى أجزاء مختلفة من النظام.

---

## لماذا يتم منعي من الدخول إلى صفحة معينة؟

لأن الصفحة تستخدم:

```php
clsHelper::requireRole()
```

للتحقق من الصلاحيات.

---

# أسئلة الطلاب

## هل يمكن نقل الطالب إلى فصل آخر؟

نعم.

من خلال تعديل:

```text
classroom_id
```

الخاصة بالطالب.

---

## هل يمكن تعطيل الطالب دون حذفه؟

نعم.

باستخدام حقل:

```text
status
```

داخل جدول الطلاب.

---

## هل يؤدي حذف الطالب إلى حذف حضوره؟

نعم.

إذا كانت العلاقة تستخدم:

```sql
ON DELETE
CASCADE
```

فسيتم حذف سجلات الحضور المرتبطة به.

---

# أسئلة الحضور

## لماذا لا يتم حفظ الحضور؟

تحقق من:

* اختيار الفصل.
* اختيار التاريخ.
* اختيار حالة الحضور لكل طالب.

---

## لماذا يمنع النظام تسجيل الحضور؟

قد يكون السبب:

```text
تم تسجيل حضور الطالب مسبقاً في نفس التاريخ
```

---

## هل يمكن تعديل الحضور بعد حفظه؟

نعم.

من خلال صفحة:

```text
تعديل الحضور
```

إذا كانت الصلاحيات تسمح بذلك.

---

# أسئلة التقارير

## لماذا لا تظهر نتائج في التقرير؟

تحقق من:

* وجود بيانات حضور.
* الفترة الزمنية المختارة.
* الفصل أو الطالب المحدد.

---

## هل يمكن تصدير التقارير؟

يمكن تطوير النظام مستقبلاً لدعم:

* PDF
* Excel
* CSV

---

# أسئلة السجلات (Logs)

## لماذا لا تظهر بعض العمليات داخل السجلات؟

تأكد من استدعاء:

```php
clsLog::add()
```

بعد تنفيذ العملية.

---

## هل يتم تسجيل جميع العمليات تلقائياً؟

لا.

يجب إضافة عملية التسجيل برمجياً داخل كل وظيفة مهمة.

---

# أسئلة التطوير

## كيف أضيف ميزة جديدة؟

يفضل اتباع الخطوات التالية:

```text
إنشاء جدول جديد
      ↓
إنشاء Class جديد
      ↓
إنشاء Module جديد
      ↓
إضافة Validation
      ↓
إضافة Permissions
      ↓
إضافة Logs
      ↓
تحديث Documentation
```

---

## كيف أضيف صفحة جديدة؟

1. إنشاء الملف داخل Module مناسب.
2. إضافة صلاحيات الوصول.
3. إضافة الرابط داخل Sidebar.
4. اختبار الصفحة.

---

## كيف أضيف جدولاً جديداً؟

1. إنشاء الجدول داخل قاعدة البيانات.
2. تحديث ملف SQL الرئيسي.
3. تحديث Database Documentation.

---

## كيف أضيف Class جديد؟

مثال:

```text
classes/clsSubject.php
```

ويكون مسؤولاً عن ميزة واحدة فقط.

---

# أسئلة الأمان

## هل يستخدم المشروع PDO؟

نعم.

ويجب استخدام:

```text
Prepared Statements
```

في جميع الاستعلامات.

---

## هل المشروع محمي من SQL Injection؟

نعم.

من خلال:

* PDO
* Prepared Statements
* Validation

---

## هل المشروع محمي من XSS؟

نعم.

من خلال:

```php
clsHelper::e()
```

عند عرض البيانات.

---

## هل يتم تشفير كلمات المرور؟

يجب استخدام:

```php
password_hash()
```

و

```php
password_verify()
```

في جميع الحسابات.
