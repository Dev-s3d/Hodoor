# دليل التثبيت والتشغيل (Installation Guide)

يشرح هذا الملف طريقة تثبيت وتشغيل مشروع Hodoor على بيئة تطوير محلية أو على استضافة تدعم PHP و MySQL.

---

# مقدمة

تم تطوير مشروع Hodoor باستخدام:

* PHP
* MySQL
* Bootstrap RTL
* Font Awesome

ويعتمد على قاعدة بيانات MySQL لحفظ البيانات الخاصة بالنظام.

يمكن تشغيل المشروع على:

* XAMPP
* MAMP
* Laragon
* WAMP
* استضافة تدعم PHP و MySQL

---

# متطلبات التشغيل

قبل تشغيل المشروع يجب التأكد من توفر:

| المتطلب    | الإصدار المقترح           |
|------------|---------------------------|
| PHP        | 8.0 أو أحدث               |
| MySQL      | 5.7 أو أحدث               |
| Apache     | أي إصدار حديث             |
| phpMyAdmin | اختياري                   |
| متصفح حديث | Chrome أو Edge أو Firefox |

---

# تحميل المشروع

قم بتحميل المشروع أو نسخه من GitHub.

مثال:

```bash
git clone https://github.com/Dev-s3d/Hodoor.git
```

أو قم بتحميله كملف ZIP ثم فك الضغط عنه.

---

# وضع المشروع داخل الخادم المحلي

## XAMPP

انسخ المشروع إلى:

```text
C:\xampp\htdocs\Hodoor
```

---

## MAMP

انسخ المشروع إلى:

```text
Applications/MAMP/htdocs/Hodoor
```

---

## Laragon

انسخ المشروع إلى:

```text
C:\laragon\www\Hodoor
```

---

# إنشاء قاعدة البيانات

قم بفتح phpMyAdmin.

ثم أنشئ قاعدة بيانات جديدة باسم:

```text
hodoor
```

أو نفذ الأمر التالي:

```sql
CREATE
DATABASE hodoor
CHARACTER SET utf8mb4
COLLATE utf8mb4_unicode_ci;
```

---

# استيراد قاعدة البيانات

من داخل phpMyAdmin:

1. اختر قاعدة البيانات.
2. اضغط Import.
3. اختر الملف:

```text
database/hodoor.sql
```

4. اضغط Go.

---

# تعديل بيانات الاتصال

افتح ملف الاتصال بقاعدة البيانات.

غالباً:

```text
config/database.php
```

أو:

```text
classes/clsDatabase.php
```

حسب نسخة المشروع.

---

# إعدادات الاتصال

مثال:

```php
private string $host = 'localhost';
private string $db_name = 'hodoor';
private string $username = 'root';
private string $password = '';
```

---

## مستخدمو XAMPP

غالباً:

```php
$username = 'root';
$password = '';
```

---

## مستخدمو MAMP

غالباً:

```php
$username = 'root';
$password = 'root';
```

# الخلاصة

لتشغيل مشروع Hodoor بنجاح:

1. تحميل المشروع.
2. إنشاء قاعدة البيانات.
3. استيراد ملف SQL.
4. تعديل بيانات الاتصال.
5. فتح المشروع من المتصفح.
6. تسجيل الدخول.
7. البدء باستخدام النظام.

تم تصميم المشروع بحيث تكون عملية التثبيت بسيطة ولا تتطلب سوى معرفة أساسية بـ PHP و MySQL.
