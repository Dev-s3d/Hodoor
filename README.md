# Hodoor - نظام إدارة الحضور المدرسي

نظام ويب متكامل لإدارة حضور الطلاب داخل المدارس، تم تطويره باستخدام PHP OOP و MySQL بهدف تسهيل عملية تسجيل الحضور،
متابعة الغياب والتأخير، وإصدار التقارير بطريقة منظمة وسريعة.

## رابط التجربة

🔗 النسخة الحية:

https://s3d.vip/projects/Hodoor/

---

## نبذة عن المشروع

يهدف Hodoor إلى تحويل عملية تسجيل الحضور التقليدية إلى نظام إلكتروني حديث يساعد الإدارة والمعلمين على:

* تسجيل الحضور اليومي بسهولة.
* متابعة الغياب والتأخير.
* إدارة الطلاب والفصول الدراسية.
* استخراج تقارير دقيقة.
* تنظيم صلاحيات المستخدمين.

## المميزات

### إدارة الطلاب

* إضافة الطلاب.
* تعديل بيانات الطلاب.
* حذف الطلاب.
* عرض تفاصيل الطالب.
* ربط الطلاب بالفصول الدراسية.

### إدارة الفصول

* إنشاء الفصول الدراسية.
* تعديل بيانات الفصول.
* حذف الفصول.
* عرض الطلاب داخل كل فصل.

### إدارة الحضور

* تسجيل الحضور اليومي.
* تسجيل الغياب.
* تسجيل التأخير.
* تسجيل الاستئذان.
* منع تكرار تسجيل الحضور لنفس الطالب في نفس اليوم.

### التقارير

* تقرير الحضور.
* تقرير الغياب.
* تقرير التأخير.
* تقرير الطلاب.
* تصفية النتائج حسب التاريخ أو الفصل.
* طباعة التقارير.
* تصدير التقارير إلى Excel.

### إدارة المستخدمين

* إنشاء المستخدمين.
* تعديل البيانات.
* تفعيل وتعطيل الحسابات.
* إدارة الصلاحيات.

### نظام الصلاحيات

#### المدير

* صلاحية كاملة على النظام.

#### المشرف

* إدارة الحضور.

* عرض التقارير.

#### المعلم

* تسجيل الحضور للفصول المخصصة له.
* عرض التقارير المسموح بها.

### لوحة التحكم

* إحصائيات مباشرة.
* عدد الطلاب.

* عدد الحضور.
* عدد الغياب.
* عدد المتأخرين.
* عدد المستأذنين.

### متجاوب مع جميع الأجهزة

## طريقة التثبيت

### 1. استنساخ المشروع

```bash
git clone https://github.com/Dev-s3d/Hodoor.git
```

### 2. إنشاء قاعدة البيانات

قم بإنشاء قاعدة بيانات جديدة:

```sql
CREATE
DATABASE hodoor;
```

### 3. استيراد ملف قاعدة البيانات

استورد ملف:

```text
database/hodoor.sql
```

### 4. تعديل ملف الاتصال

```php
config/database.php
```

ثم أدخل بيانات قاعدة البيانات الخاصة بك.

### 5. تشغيل المشروع

```text
http://localhost/Hodoor
```
