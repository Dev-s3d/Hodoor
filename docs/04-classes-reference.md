# مرجع الكلاسات (Classes Reference)

يحتوي مشروع Hodoor على مجموعة من الكلاسات المسؤولة عن تنفيذ منطق النظام والتعامل مع قاعدة البيانات والصلاحيات والجلسات
والتقارير.

يهدف هذا الملف إلى توضيح مسؤولية كل Class ودوره داخل النظام.

---

# نظرة عامة

جميع الكلاسات موجودة داخل المجلد:

```text
classes/
```

الهيكل الحالي:

```text
classes/
│
├── clsUser.php
├── clsStudent.php
├── clsClassroom.php
├── clsAttendance.php
├── clsReport.php
├── clsSetting.php
├── clsHelper.php
├── clsValidator.php
├── clsPath.php
└── clsLog.php
```

# العلاقات بين الكلاسات

يعمل النظام بطريقة مترابطة بين الكلاسات.

مثال عند تسجيل الحضور:

```text
attendance/save.php
        ↓
clsValidator
        ↓
clsAttendance
        ↓
Database
        ↓
clsLog
```

# ملاحظات التطوير

عند إضافة أي ميزة جديدة يجب مراعاة ما يلي:

* إنشاء Class مستقل للمسؤولية الجديدة.
* عدم وضع منطق الأعمال داخل الصفحات.
* استخدام clsValidator للتحقق من البيانات.
* استخدام clsLog لتسجيل العمليات المهمة.
* استخدام clsHelper لإدارة الجلسات والصلاحيات.
* استخدام clsPath لإنشاء المسارات.

---

# الخلاصة

تمثل الكلاسات الموجودة داخل مشروع Hodoor الطبقة المسؤولة عن تنفيذ منطق الأعمال (Business Logic) وإدارة العمليات الأساسية
للنظام.

وقد تم تصميمها بحيث تكون:

* قابلة لإعادة الاستخدام.
* سهلة الصيانة.
* سهلة التطوير.
* قابلة للتوسع مستقبلاً.
