# Hodoor

نظام إدارة حضور مدرسي مطور بلغة PHP بأسلوب OOP، يساعد المدارس والمعلمين على إدارة حضور الطلاب، متابعة الغياب والتأخير،
وإصدار التقارير بشكل منظم وسهل الاستخدام.

---

# نبذة عن المشروع

Hodoor هو نظام حضور مدرسي إلكتروني يهدف إلى تحويل عملية تسجيل الحضور التقليدية إلى نظام رقمي حديث يدعم:

- إدارة المستخدمين والصلاحيات
- إدارة الطلاب والفصول
- تسجيل الحضور اليومي
- متابعة الغياب والتأخير
- إصدار التقارير
- نظام صلاحيات متعدد
- واجهة متجاوبة تعمل على جميع الأجهزة

# طريقة تشغيل المشروع

## 1) رفع المشروع

ضع المشروع داخل:

```text
htdocs/Hodoor
```

إذا كنت تستخدم XAMPP.

---

## 2) إنشاء قاعدة البيانات

أنشئ قاعدة بيانات جديدة:

```sql
hodoor
```

ثم قم باستيراد ملف:

```text
database/hodoor.sql
```

---

## 3) تعديل بيانات الاتصال

داخل:

```text
config/database.php
```

قم بتعديل:

```php
$host = 'localhost';
$dbname = 'hodoor';
$username = 'root';
$password = '';
```

---

## 4) تشغيل المشروع

افتح المتصفح:

```text
http://localhost/Hodoor
```
