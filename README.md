# نبذة عن المشروع

**Hodoor** هو نظام لإدارة حضور الطلاب تم تطويره باستخدام لغة PHP وقاعدة بيانات MySQL بأسلوب البرمجة الكائنية (OOP).

يهدف المشروع إلى مساعدة المدارس والمعاهد والمراكز التعليمية في إدارة حضور الطلاب بطريقة منظمة وسهلة مع توفير أدوات
لإدارة المستخدمين والطلاب والفصول الدراسية والتقارير وسجل العمليات.

# التثبيت السريع

## 1. تحميل المشروع

```bash
git clone https://github.com/Dev-s3d/Hodoor.git
```

---

## 2. إنشاء قاعدة البيانات

```sql
CREATE
DATABASE hodoor;
```

---

## 3. استيراد قاعدة البيانات

```text
database/hodoor.sql
```

---

## 4. تعديل بيانات الاتصال

مثال:

```php
$host = 'localhost';
$dbname = 'hodoor';
$username = 'root';
$password = '';
```

---

## 5. تشغيل المشروع

```text
http://localhost/Hodoor
```
